Link preview — final choices

These are Rachit's final picks. All three must be in the site before it goes live. The files are in the same folder as this document. The HTML to paste into the page is at the bottom.

1 — The description

Designing products that are genuinely useful for people. Health tech, accessibility and EdTech, based in the UK.

112 characters. Under the 160-character limit for search results.

2 — The preview picture

Shown when someone shares the link on LinkedIn, WhatsApp, Slack or in an email. The file is link-preview-image.jpg (also available as link-preview-image.png). It is already at the correct size: 1200 × 630 pixels.

Put this file in your site's public folder (e.g. /public/link-preview-image.jpg) and reference it in the meta tags below. Some apps trim the edges slightly, so the important content — Rachit's face and name — sits in the middle.

3 — The tab icon (favicon)

The RP monogram on a dark rounded square. It shows in the browser tab, bookmarks, and home screen shortcuts. All files are included.

4 — Files to put in the site

favicon.svgThe icon as an SVG. Use this as the primary favicon — modern browsers prefer it and it scales perfectly.
favicon-512.png512 × 512 PNG. Used for Android home screen shortcuts and PWA icons.
favicon-192.png192 × 192 PNG. Android home screen shortcut, standard size.
favicon-180.png180 × 180 PNG. Apple touch icon — shown when someone adds the site to an iPhone home screen.
favicon-32.png32 × 32 PNG. Fallback for browsers that don't support SVG favicons.
favicon-16.png16 × 16 PNG. Smallest fallback.
link-preview-image.jpg1200 × 630 JPEG. The preview picture for shared links. Use this for the og:image tag.
link-preview-image.png1200 × 630 PNG. Same picture, lossless. Use as a fallback if needed.

5 — HTML to paste into the <head> of portfolio.html

Replace your-website-address.com with the real domain once it is known. Everything else is final.

Also create a site.webmanifest file

This is a small text file needed for the manifest link above. Put it at /site.webmanifest (in the site root) with this content:

{ "name": "Rachit Patni — Product Designer", "short_name": "Rachit Patni", "icons": [ { "src": "/favicon-192.png", "sizes": "192x192", "type": "image/png" }, { "src": "/favicon-512.png", "sizes": "512x512", "type": "image/png" } ], "theme_color": "#18181b", "background_color": "#f9f7f2", "display": "browser" }

6 — After deploying, check these

  • Paste the live URL into developers.facebook.com/tools/debug and click "Scrape Again". This is the most reliable way to see the LinkedIn and Facebook card.
  • Paste the live URL into a LinkedIn post draft (don't publish it) and confirm the picture and description appear.
  • Open the site in Chrome and confirm the RP icon appears in the browser tab.
  • On an iPhone, tap the Share button and "Add to Home Screen" — confirm the icon appears correctly.
  • Update the two your-website-address.com placeholders in the meta tags once the domain is confirmed.
